# 🚀 EDC BBIT — Official Website & Core Member Portal
**Entrepreneurship Development Cell | Budge Budge Institute of Technology (BBIT), Kolkata**

Welcome to the official repository for the **EDC BBIT** website. Designed and developed by **Shruti Biswas** (Developer & Organizer) for the students and core committee of the Entrepreneurship Development Cell at BBIT.

---

## 🌟 Highlights & Features

- **Official Identity & Logo**: Integrated high-resolution EDC BBIT logo, sapphire-cyan color theme matching the cell's brand identity, and the official motto: *"From Job Seekers to Job Creators"*.
- **Core Member Self-Registration**:
  - Interactive "+ Register as Core Member" modal for organizers and leads to add their designation, department, bio, skills, LinkedIn/GitHub links, and photo.
  - Stored dynamically in browser `localStorage` with real-time UI updates.
  - **Export JSON** feature: Organizers can export the updated team roster to permanently commit into `assets/js/data.js`.
- **Student Onboarding Portal**:
  - Educates students across all departments (CSE, CSE-AI, IT, EE, ME, CE, ECE, MBA) on what EDC does, its incubation initiatives, and hackathons.
  - Interactive "Join the Cell" registration form.
  - Generates an instant **Digital EDC BBIT Membership Pass** with unique Member ID and QR code badge.
- **Flagship Events Showcase**:
  - Highlights milestones like **INNOV8 3.0** (32-hour hackathon), **Innovation Ignite 5.0**, and upcoming **E-Summit 2026**.
- **Social Connectivity**:
  - Prominent links to the [Official EDC BBIT LinkedIn](https://www.linkedin.com/company/ed-cell-bbit/).

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup, accessible dialog modals (`<dialog>`), structured meta tags.
- **Modern CSS3**: Glassmorphism, CSS Custom Properties, flexbox/grid responsive layouts, smooth scroll, dark theme with blue & cyan accents.
- **Vanilla JavaScript**: Zero build tools required; works offline and online with `localStorage` state management and dynamic DOM rendering.

---

## 🚀 Getting Started

Simply open `index.html` in your browser, or run a local server:

```bash
# Using npx serve:
npx serve .

# Or using Python:
python -m http.server 8000
```
